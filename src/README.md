# Banking Information System

## Description
A console-based Banking Information System developed using Core Java.

## Features
- User Registration
- Login
- Deposit Money
- Withdraw Money
- Check Balance
- Transaction History
- File Handling
- Exception Handling

## Technologies Used
- Java
- Object-Oriented Programming
- Collections (ArrayList)
- File Handling
- Exception Handling

## How to Run

Compile:
```bash
javac *.java
```

Run:
```bash
java Main
```
