# Banking Information System

## Description
A console-based Banking Information System developed using Core Java. This project allows users to create bank accounts, log in, deposit and withdraw money, check account balance, update mobile numbers, and view transaction history.

## Features
- User Registration
- Login
- Deposit Money
- Withdraw Money
- Check Balance
- Transaction History
- Update Mobile Number
- File Handling
- Exception Handling
- Input Validation

## Technologies Used
- Core Java
- Object-Oriented Programming (OOP)
- ArrayList
- File Handling
- Exception Handling
